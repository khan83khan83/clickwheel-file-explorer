# Clickwheel File Explorer

A mouse-driven file browser for Windows 11 with a classic clickwheel-inspired interface, cover previews, Cover Flow, and a built-in PDF reader. Written in Python with PySide6 and PyMuPDF.

## Controls

| Input | Action |
| --- | --- |
| Mouse wheel | Move through menu rows, covers, or PDF pages |
| Left click | Open the selected item or toggle the reader HUD |
| Right click | Go back one level |
| Ctrl+E (default) | Show or hide the side panel |

Folders and files follow the existing browser behavior. PDFs open through the configured Windows reader integration; other files use their Windows associations. The tray menu offers a standalone window, startup at sign-in, and Quit. Appearance, folder selection, navigation restoration, and preview caching are retained.

## Run from source

Requires Windows 11 and Python 3.12, 64-bit.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Use `run.bat` for a launch without a console, or pass `--background` to start in the tray.

## Build

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe -m PyInstaller --noconfirm --windowed --onedir --name "Clickwheel File Explorer" --icon assets\icons\app.ico --version-file version_info.txt --add-data "assets;assets" main.py
```

Run `dist\Clickwheel File Explorer\Clickwheel File Explorer.exe`. Keep the adjacent `_internal` directory with the executable. Python is not required for the packaged app.

## Settings and upgrades

Settings and reading state live in `%APPDATA%\ClickwheelFileExplorer`; cover caches and logs live in `%LOCALAPPDATA%\ClickwheelFileExplorer`. Upgrading from either former app name automatically migrates existing settings, reading positions, cover caches, and enabled startup shortcuts. Old names appear in the migration code only for compatibility.

Your saved library folder, hotkey, appearance, and navigation state take precedence over defaults. User data is stored separately from this repository. The default for a new profile is the user's Documents folder. PDF launching prefers Lucid PDF Reader when installed, then the default handler, with Edge as a fallback.

## Tests

Tests are executable Python scripts in `tests/`. Run them separately: some set up their own temporary profiles. For a fully isolated check, set `APPDATA` and `LOCALAPPDATA` to temporary directories and supply a small sample library in that profile's `config.json` before running the scripts. Some integration tests inspect an existing library or exercise Windows hotkeys; those should be run on a Windows desktop.

```powershell
.venv\Scripts\python.exe tests\test_migrate.py
.venv\Scripts\python.exe tests\test_autostart.py
```
